רגע, זה לא בעצם תוכנה שמקליטה הקלדות?

כדי לזהות ג'יבריש, Fixi חייב לראות את ההקלדה. ההבדל הוא מה קורה איתה: היא נשארת בזיכרון בלבד, לכל היותר 20 מילים, ונמחקת כל הזמן. היא אף פעם לא נשמרת בקובץ ואף פעם לא נשלחת, כי אין ב-Fixi קוד שמתחבר לאינטרנט. בשדות סיסמה ש-Windows מזהה הוא לא נוגע. יש תוכנות, כמו VS Code, Slack ו-Teams, שלא מדווחות ל-Windows איזה שדה הוא שדה סיסמה, ולכן שם Fixi לא יכול לזהות אותו. אפשר להחריג כל תוכנה כזאת בהגדרות, ואז Fixi לא מחזיק ממנה אפילו אות אחת בזיכרון.

Started typing Hebrew while the keyboard was still in English? Fixi notices, rewrites the whole sentence and switches the keyboard language. By itself, in a second, with no deleting and retyping.

How it works

  1. Type as usual, in any app. Forget to switch language, as always.
  2. Fixi sees it is gibberish, and waits for a second word to be sure.
  3. The sentence is fixed, the keyboard is switched, and you keep typing.

What it does

  • Both directionsHebrew typed as English, and English typed as Hebrew.
  • The whole sentenceNot just the last word: everything typed in the wrong language.
  • Undo in a secondDidn't want that? Tap Ctrl twice and it is all back.
  • Fix on demandTap Shift twice to flip what you just typed.
  • CapsLock tooIf that is how you switch to English, Fixi understands.
  • You are in controlPause in one click, and exclude any app you like.

Never connects to the internet. At all.

To fix your typing Fixi has to see it, so it had to be built carefully: what you type stays in memory only, at most your last 20 words, cleared on every Enter, window switch, mouse click and correction. Nothing is written to disk, and Fixi contains no networking code. Read the full privacy policy

Questions

Wait, isn't this a keylogger?

To notice gibberish, Fixi has to see your typing. What matters is what happens to it: it stays in memory only, at most 20 words, cleared constantly. It is never saved to a file and never sent anywhere, because Fixi has no code that connects to the internet. It stays out of password fields Windows can identify. Some apps, such as VS Code, Slack and Teams, do not tell Windows which field is a password, so there Fixi cannot recognise one. You can exclude any such app in Settings, and then Fixi does not hold a single letter from it, even in memory.

Which apps does it work in?

Most apps you type in on Windows, for example Chrome, Word, Notepad, Notepad++ and VS Code. The exception is windows running as administrator: Windows does not let any app correct text there.

What do I need?

Windows 10 (version 1809 or later) or Windows 11, with Hebrew and English keyboards installed.

Tap Ctrl twice to get back exactly what you typed and your keyboard language, and Fixi will not touch those words again. It is built to prefer missing a fix over making a wrong one: it waits for two words before it changes anything.
